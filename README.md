A one-page infographic summing up world news of Wednesday, 18 November 2026: the Quad summit in Manila, the Crimean bridge strikes, Iran's drone attack on a US radar base in Bahrain, Taiwan's $14bn arms decision, Canada–China trade, and the US losing measles-free status. The image is drawn programmatically by render.py (Pillow) so every word is crisp, legible text, and main.ts copies it to the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
